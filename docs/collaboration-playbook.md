## Collaboration rules for agents

1. Treat the Obsidian vault as context memory, not as a place to write private content casually.
2. Prefer creating operational docs in the repo first unless the user explicitly wants vault notes.
3. Reduce chaos before adding more surface area:
   - normalize naming
   - separate draft vs published
   - consolidate sources of truth
4. Favor parallel execution with clearly owned write scopes.
5. Leave audit trails in Markdown.
